Virtual DOM (The Solution)
    The Virtual DOM is a lightweight JavaScript object copy of the real DOM.
    When data changes, React builds a brand new Virtual DOM tree, compares it
    against a snapshot of the old Virtual DOM (a process called Diffing),
    figures out exactly which individual elements changed, and applies only
    those specific edits to the real DOM in one single batch.

# prompt:
    how do I access the virtual dom in reactjs directly from javascript?

    Result:
        import { useRef, useEffect } from 'react';

        function MyComponent() {
        // 1. Create the reference container
        const inputRef = useRef(null);

        useEffect(() => {
            // 3. Access the actual DOM element safely using plain JS methods
            if (inputRef.current) {
            inputRef.current.focus(); 
            }
        }, []);

        // 2. Attach the ref to the element
        return <input ref={inputRef} type="text" />;
        }

        Understanding the React Ecosystem
            While you cannot touch the "Virtual DOM" tree while it computes updates,
            your intention usually maps to one of two things in React:
            1. Inspecting the Virtual Tree (For Debugging)
                If you want to view the structure of the virtual tree, its props,
                and its current state, you must use the official React Developer Tools
                extension.
                - Once installed, it adds a "Components" tab to your browser’s DevTools.
                - Selecting a component there lets you inspect its virtual properties.
                - You can also type $r in your browser's regular JavaScript console to get
                  a direct reference to that specific selected React component instance.
            2. Accessing Underlying HTML Nodes (For DOM Manipulation)
                If your goal is to manipulate, measure, or focus a specific element on the
                page, React provides a feature called Refs (useRef or createRef). This gives
                you a direct handle on the real DOM node once React has finished updating it,
                bypassing the need for standard JavaScript lookups.
