        A .jsx file is:
            basically a javascript xml file for react.

            How JSX WorksNot Real HTML: Although it looks like HTML, it is transformed
                into regular JavaScript (such as React.createElement calls) by tools like Babel before the browser runs it.
            Embedding Logic: You can put JavaScript variables or math inside your tags
            by using curly braces {}.
            Main Rules of JSX
                Single Root: Every block must have one single parent element (like a <div> or an empty fragment <>).
                CamelCase Names: HTML attributes use camelCase in JSX, meaning class becomes className and for becomes html For.
                Closed Tags: All tags must close properly, including self-closing tags like <br /> or <img />.


        type="text/babel" 
            tells an in-browser Babel standalone compiler that it needs to transform modern
            JavaScript and JSX code into standard, browser-compatible JavaScript
